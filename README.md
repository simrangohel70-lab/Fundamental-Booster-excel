# 📖 About the Project

**Fundamental Booster** is an Excel-based data analysis project created to practice and demonstrate practical knowledge of **Microsoft Excel formulas, functions, calculations, and data analysis techniques**.

The workbook contains multiple datasets and applies different Excel functions to transform raw data into meaningful and structured information.

### 📂 Datasets Included

📚 **Student Data**
💰 **Sales Data**
👨‍💼 **Employee Data**

The project focuses on applying formulas, lookup functions, conditional logic, date calculations, and rounding techniques to solve practical data-related tasks.

---

# ✨ Key Features

| Feature                     | Description                                       |
| --------------------------- | ------------------------------------------------- |
| 📚 **Student Analysis**     | Calculate total marks, percentage and grades      |
| 💰 **Sales Analysis**       | Calculate sales values, discounts and eligibility |
| 👨‍💼 **Employee Analysis** | Analyze salary and joining-date information       |
| 🔎 **Lookup Operations**    | Search and retrieve required information          |
| 📅 **Date Analysis**        | Perform date-based calculations                   |

| 🎯 **Conditional Analysis** | Apply logical conditions to datasets              |
| 🔄 **Dynamic Calculations** | Create formulas that update automatically         |
| 📊 **Data Formatting**      | Organize data into a clean structure              |

# 🧮 Formula Showcase

This project demonstrates the practical use of different Excel functions.

### 🔢 Mathematical & Rounding Functions

```excel
SUM()
AVERAGE()
ROUND()
CEILING()
FLOOR()
```

| Function    | Purpose                                      |
| ----------- | -------------------------------------------- |
| `SUM()`     | Calculate total values                       |
| `AVERAGE()` | Calculate average values                     |
| `ROUND()`   | Round values to a specified number of digits |
| `CEILING()` | Round a value upward                         |
| `FLOOR()`   | Round a value downward                       |

---

### 🔎 Lookup & Reference Functions

```excel
VLOOKUP()
XLOOKUP()
INDEX()
MATCH()
```

Used for:

* 🔎 Searching records
* 📋 Retrieving information
* 📊 Finding corresponding values
* 🔄 Performing dynamic lookups

---

### 📅 Date & Time Functions

```excel
DATEDIF()
YEAR()

TODAY()
```

Used for:

* 📅 Working with dates
* ⏳ Calculating years since joining
* 📊 Extracting date information
* 🔄 Performing date-based calculations

### 🎯 Conditional Functions

Used for:
